Usage & Security Notes

  1. This page generates a QR code (barcode) that can be scanned into an authenticator app that generates Time-based One Time Passwords (TOTP) compliant with IETF RFC 6238. Such apps include Google Authenticator, Microsoft Authenticator, and numerous others.

  2. This tool constructs an otpauth://totp/... URI from your Label, Secret, and Issuer, and sends the payload to an online chart renderer (such as quickchart.io) to generate the barcode image. You should use this only for demonstrations or testing.

  3. The combination of {Label, Secret, Issuer} is sufficient to generate matching one-time codes and impersonate an account. Never use an online tool to generate QR codes for sensitive production secrets. For more details, see this Stack Overflow answer.

  4. This tool runs entirely in the browser using client-side JavaScript.
