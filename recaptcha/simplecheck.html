reCAPTCHA v3

Simple Score Check

Execute Google reCAPTCHA v3 on the client side, send the verification token to an Apigee backend proxy, and inspect the risk score returned by Google.

Click Check Score to execute the homepage action. A token will be generated in the background and verified against the backend assessment endpoint.

Documentation

How This Check Works

  1. Token Generation: grecaptcha.execute() requests an encrypted verification token associated with this demo site key and the homepage action.
  2. Backend Postback: The token is POSTed as JSON to an Apigee API proxy (https://gaccelerate3-test.apigee.net/recaptcha-v3/check).
  3. Assessment: The Apigee proxy forwards the token and site secret to Google's siteverify API and returns the assessment response containing success, score, action, and challenge_ts.
  4. Score Interpretation: 1.0 represents a very high likelihood of a human user; 0.0 represents an automated bot or high-risk interaction.
