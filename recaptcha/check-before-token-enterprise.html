Token Protected by reCAPTCHA Enterprise

Protect OAuth 2.0 Client Credentials token requests using Google Cloud reCAPTCHA Enterprise verification tokens to guard against automated bot abuse.

Documentation

How Enterprise Token Protection Works

  1. Dynamic Enterprise Execution: The page injects Google's Enterprise SDK and calls grecaptcha.enterprise.execute() for the token action.
  2. Protected Endpoint Postback: The client sends an HTTP POST request to ${baseurl}/oauth2-cc-recaptcha/token with Basic Auth headers and the recaptcha-token header.
  3. Server-Side Assessment: Apigee verifies the token with the Google Cloud reCAPTCHA Enterprise Assessments API. If score and risk reasons pass the configured security threshold, the OAuth 2.0 token is issued.
  4. Local Persistence: Configuration settings (Base URL, Site Key, Client ID/Secret) are saved to window.localStorage so they persist across page reloads in this browser.
