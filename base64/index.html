Usage & Encoding Notes

  1. This page decodes and encodes text locally in your browser. Any data you enter stays on your machine and is never sent to any server.
  2. Base64-encoded values are case sensitive. This is a fundamental characteristic of the encoding.
  3. When encoding message content:
    1. Unicode characters and emojis are fully supported via UTF-8 byte serialization.
    2. Whitespace in the content is significant. For example, the encoding for abc\n is different from abc.
    3. Trailing newlines are preserved.
    4. Line-breaks are converted to standard newlines (\n).
  4. When decoding, not all binary sequences can be decoded into printable UTF-8 strings.
