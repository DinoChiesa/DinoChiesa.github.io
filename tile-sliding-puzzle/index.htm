About Sliding Tile Puzzle

This is an interactive HTML version of the tile sliding puzzle. Click on a tile adjacent to the open space to move it.

The auto-solver uses Dijkstra's A* heuristic search to find the optimal sequence of moves to the solved state.

Key Findings & Optimizations

  1. Heuristic: Manhattan distance combined with linear conflict works substantially better than simple Manhattan distance alone.
  2. Asynchronous search loop: The search explores thousands of nodes. To avoid freezing the browser, the loop is unrolled and made asynchronous with setTimeout().
  3. Past-to-future ratio: Standard A* weights past moves and estimated remaining moves equally (1:1), causing an exponential node explosion on a 15-puzzle. Biasing the search toward future progress (a 3:1 to 4:1 ratio) prevents the browser from stalling and quickly yields near-optimal solutions.
  4. State representation: A compact 16-character string representation for the state yields far better performance in JavaScript than 2-D numeric arrays when checking against the “closed” set.
  5. Precomputed adjacency: Tile neighbor adjacencies are precomputed into a static lookup table, avoiding neighbor search overhead at runtime.
