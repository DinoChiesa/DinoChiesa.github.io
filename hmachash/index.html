Usage & Cryptographic Notes

  1. This page uses the WebCrypto library for hash and HMAC computation.
  2. Any data you enter on this page stays in the browser and is never sent to any server. The hash computation is performed locally in your browser. If you specify a key for HMAC, the key never leaves your browser. Inputs are saved in localStorage for your convenience.
  3. The results shown represent different encodings of the same digest byte array. Base16 (Hex) is case-insensitive, while Base64 and Base64Url are case-sensitive.
  4. For message content, whitespace is significant. This page converts line-breaks to newline (\n). Trailing newlines are preserved: the hash for abc\n is completely different from the hash for abc.
  5. Unicode is fully supported. The calculator encodes text strings as UTF-8 bytes prior to computing checksums.
  6. Written by DinoChiesa. Contact via GitHub or Bluesky.
